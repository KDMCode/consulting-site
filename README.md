# consulting-site

A short static page for independent consulting. The title "Consulting" is a placeholder.

The future public URL will be https://kdmcode.github.io/consulting-site/ once GitHub Pages is turned on. Turning Pages on is a repository setting (Settings → Pages → Deploy from a branch → `main` → `/ (root)`). These files do not enable it.

Open `index.html` to view the page. Styles are in `styles.css`. There is no build step. `.nojekyll` keeps Pages from running the site through Jekyll.
